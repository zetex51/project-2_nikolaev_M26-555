# Primitive DB

Минимальный устанавливаемый консольный пакет для проекта по созданию
примитивной базы данных.

## Запуск

```sh
uv sync
uv run python -m primitive_db.main
uv run project
```

Приложение покажет команды `help` и `exit`. Команда `help` выведет список команд
повторно, а `exit` завершит программу.

## Сборка пакета

```sh
uv build
```
